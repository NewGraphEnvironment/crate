## Outcome

Scaffolded crate as a public R package and shipped its first executable surface — `crt_ingest(source, file_name, path)` source-explicit dispatcher with first-instance handler for `bcfp/user_habitat_classification` (handles both pre-2026-04-26 long and current 2026-04-26 wide upstream variants → canonical wide). Established the patterns crate's data-governance layer will reuse as more domains land: schema YAML format under `inst/extdata/schemas/<source>/<file>.yaml`, decision-log entries under `decisions/<source>/<dated-topic>.md`, registry CSV under `inst/extdata/`, internal handlers `R/internal_<source>_<file_name>.R`, and the `crate::crt_ingest()` dispatcher API consumed by downstream packages. R package machinery mirrors flooded conventions (DESCRIPTION, NAMESPACE via roxygen, lintr config, dev/dev.R, pkgdown.yaml deploying to gh-pages — no separate R-CMD-check workflow per NGE family practice).

Key learning surfaced during plan-mode exploration: original issue body sketched **long-canonical** for `user_habitat_classification`; three independent signals (fresh 0.22.0's enforced wide API, link's SQL schema, current upstream state) revealed the canonical is **wide**. Decision log records the rationale; issue body got a post-merge resolution note preserving the planning record below the correction. Other patterns established: `# nolint: object_usage_linter.` for known cross-file false positives in same-package function refs and cli string interpolations; `lintr::object_length_linter(50)` to permit `internal_<source>_<file_name>` naming; flooded's hex sticker script copied verbatim (reads pkg name from DESCRIPTION); pkgdown deploys to gh-pages and is gated on Pages being enabled in repo settings.

Also surfaced for soul convention propagation (deferred to user discussion): "public READMEs reference only public repos; CLAUDE.md (visible internally; for crate, deliberately public) carries the full ecosystem map."
