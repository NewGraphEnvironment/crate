# crate: Canonical Schemas and Data Governance for Changing Data

Source-explicit dispatcher and declarative schemas for canonicalizing
heterogeneous data inputs across the New Graph Environment ecosystem.
Ships canonical-shape schemas, decision logs, and adapter functions that
insulate downstream consumers (link, fresh, reporting repos) from
upstream-shape variability. First instance: bcfishpass override CSVs.
Also holds the provenance receipt contract: a JSON Schema, RFC 8785
canonical JSON, a table fingerprint and test vectors, with R functions
that write receipts and compare two builds as identical, equivalent
within a declared tolerance, or different.
